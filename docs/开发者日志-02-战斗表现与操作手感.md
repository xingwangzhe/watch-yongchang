# 开发者日志 02：让战斗看得懂、打得准、跑得动

- 日期：2026-11-24
- 作者：xingwangzhe
- 阶段：战斗表现、操作引导、地图一致性与性能收敛

## 问题

玩法骨架完成后，验收暴露了三类问题：箭塔只有抽象伤害，玩家不容易判断攻击方向；地图瓦片的外观与实际通行规则不一致；大量敌人和特效出现时，节点与绘制调用增长过快。

## 关键实现

- 箭塔改为真实可见的齐射，并加入独立 burst lane。新齐射不会清掉旧队列，因此可以连发和重叠并发；对应升级进入三选一卡池。
- 删除旧攻击辅助圆弧，改由攻击特效表达碰撞。主角周围增加跟随鼠标矢量的短方向弧，半径 82px，并配切线箭头。
- 输入支持长按连续攻击、0.18 秒单击缓冲和 `X` 自动攻击切换；自动模式选择最近的存活敌人。
- 首次游玩加入操作、文化背景、游戏系统三页双语教程；升级三选一出现后的第一秒锁定输入。
- 水面统一为可通行，桥面在生成阶段补齐并连续绘制；渲染、碰撞、流场与小地图共享同一套地形语义。
- 盾牌从主角兵器池移除，只保留防御向升级。

## 性能处理

460 敌人压力场景的 draw calls 从约 930 降到 14。当前桌面会话本身只有约 1 实际帧/秒，空场景也如此，因此绝对 FPS 必须在正常唤醒的原生桌面或 Windows 环境复测，不能把本地软件会话的数字当成最终性能结论。

## 验证

新增和更新了地图连通性、攻击输入、方向弧、升级锁、箭塔并发和导出过滤回归测试。当前 Linux GUT 基线为 **164 tests / 164 passed / 41203 asserts**。相关提交包括 `d2ddab7`、`03751c9`、`9a0ea8b`、`acedc97` 和本轮整改提交 `a2ead17`。
