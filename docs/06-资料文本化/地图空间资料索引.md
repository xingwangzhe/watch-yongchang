# 永昌堡与宁村所 · 地图空间资料索引

> 索引范围：永昌堡城墙、城门、水门、敌台、护城河、双渠、街巷、桥梁，以及宁村所十字街、七星河、护城河的空间记载。
> 访问日期：2026-11-23。
> 用途：为 `game/data/maps.json` 的三张地图提供可追溯的空间依据；区分史实、制度、民俗与演绎，不把游戏比例冒充测绘数据。
> 关联文档：`docs/06-资料文本化/堡与汤和关系索引.md`、`design/肉鸽地图重设计方案.md`。

## 1. 先说结论

1. 永昌堡不是一张均匀的方形贴图：它有 **4 座陆门、4 座水门、12 座敌台、两条南北水渠、护城河、街巷与桥梁**。这些结构可以直接转成游戏里的墙、水、桥、门、塔和出生带。
2. 不同来源的尺寸不一致：南北有 **757 米**与 **738.3 米**两种口径，东西有 **449 米**与 **445.4 米**两种口径；桥梁数量也有 **11 座**与 **5 座石桥**的不同统计范围。本文并列记录，不合并成单一“绝对事实”。
3. 游戏采用 **真实拓扑 + 可玩比例压缩**：水门夜潮与十字街按 96×160 格、每格 32 像素建造，1 格约 4.6–4.7 米；这是为了 16 分钟单局、460 敌人上限与桥头战斗服务的转译，不是考古测绘。
4. 叙事红线不变：**1386 年汤和筑宁村所；1559 年永昌堡由王氏营建；1559 正篇主角是虚构守灯乡勇王陆（阿六）**。不得写“汤和筑永昌堡”。

## 3. 空间事实如何转成游戏地图

### 3.1 比例与网格

- 水门夜潮、十字街：`96 × 160` 格，格宽 32 像素。
- 若按南北 738.3–757 米计算，160 格对应每格约 **4.6–4.7 米**；东西 96 格约 **441–451 米**，与 445–449 米口径接近。
- 该比例只保证“城墙、双渠、街坊、桥头”的相对关系，不保证每栋建筑、每条巷道的真实位置。
- 滩涂夜：`120 × 84` 格，是永昌堡外的海岸滩涂，不是城堡平面；用潮沟、盐坂、旧海塘表达“开放但有切割”的战场。

### 3.2 已落实的真实结构

| 真实结构 | 水门夜潮 | 十字街 | 滩涂夜 |
|---|---|---|---|
| 城墙与陆门 | 四面墙、4 陆门（迎川/通市/镇山/环海） | 四面墙、4 陆门 | 旧海塘与局部堤墙 |
| 水门 | 4 水门，南北各二 | 4 水门，南北各二 | 无（以外海与潮沟代替） |
| 敌台 | 12 座，沿墙分布 | 四角敌台 | 旧海塘望台 |
| 护城河 | 环绕城墙外 | 外圈水道 | 外海与潮沟 |
| 两条南北水渠 | 上河、下河 | 上河、下河 | 两条潮沟 |
| 桥 | 渠桥、门桥、护城河桥 | 渠桥、门桥 | 潮沟桥、海塘桥 |
| 街巷 | 环墙路 + 中轴路 + 横向连桥路 | 十字主街 + 横巷 + 沿渠街 | 土路、盐坂小径 |

### 3.3 明确属于演绎的部分

- 具体街坊数量、每栋房屋的尺寸与位置。
- 敌台在游戏中的精确间距、桥面宽度与可通行半径。
- 滩涂的潮沟走向、盐坂形状、旧海塘位置。
- 守夜敌人从哪些“出生带”进入、何时涌入、走哪条桥。
- 王陆的守夜阵位与灯火点位。

以上均标为“演绎”，不得写成考古结论。

## 6. 代码与数据落点

| 文件 | 作用 |
|---|---|
| `game/data/maps.json` | 三图固定世界尺寸、地形、道路、水域、桥、墙、敌台、建筑、门、地标、出生带 |
| `game/scripts/actors/map_layout.gd` | 碰撞格、水域/桥面、可达性、流场寻路、小地图底图 |
| `game/scripts/actors/map_renderer.gd` | 三层 `TileMapLayer` 绘制与碰撞/小地图同步 |
| `game/scripts/actors/battlefield.gd` | 玩家/敌人/弹道受墙体与水渠约束；出生带刷怪；流场导航 |
| `game/scripts/ui/minimap.gd` | 实时小地图：底图、地标、玩家朝向、敌人、拾取物、镜头框、北向 |
| `game/tests/unit/test_map_layout.gd` | 空间结构、道路阻挡、出生连通、相机边界、小地图 HUD 检查 |

## 7. 未采用与待核实

- 温州博物馆与浙江日报的桥数差异未继续追查原始测绘报告；游戏不宣称“11 座桥”或“5 座桥”为唯一答案。
- 永昌堡内部具体街巷名、建筑功能分区未有完整公开图；十字街的街坊排布属于演绎。
- 宁村所七星河的具体走向未取得可复核的逐段坐标；滩涂夜只借用“潮沟切割 + 桥涵回环”的空间意象。
- 任何后续新增地图，必须先补来源、分类与转译说明，再改 `maps.json`。
