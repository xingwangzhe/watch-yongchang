## 视觉主题总结（供美术与玩法参考）

1. **主色调**：红、黄、金为绝对主导，配以龙身的蓝/绿/黑；灯笼、彩旗、红毯构成喜庆视觉。
2. **核心符号**：拼字龙灯（可拼"天下太平"等字）、汤和雕像、香亭花车、仪仗旗、米塑供品。
3. **场景类型**：街巷巡游、广场演出、室内剧场、祭祀供桌、古村落、百家宴。
4. **玩法映射**：
   - 五龙配色 → 五支龙灯队兵种/五行属性
   - 拼字"天下太平" → 阵形拼字玩法/终极技能
   - 巡游队伍 → 波次推进动画
   - 香亭/祭祀 → 信仰资源与建筑
   - 百家宴/米塑 → 士气事件卡与图鉴
