# v1.6.0

## 内容

- 新增 OpenAI ImageGen 独立兵器部件并接入 CharacterForge 烘焙；武器仍按阵营与握持规则组合。
- 将望楼、箭楼、龙首箭楼改为模型生成大图切片素材；保留 Pillow 切片与最近邻缩放流程。
- Web 竖屏显示横持提示并随视口变化重排触控 UI；手机 Web 限制最多 120 名敌人，桌面 Web 限制 180 名。
- 每局加入一张由种子选出的“十三进士”可选祝福；人物来源取自项目地方史文本，效果标注为演绎。
- Web 发布预设包含 CharacterForge 运行时数据与脚本。

## 验证

- Linux GUT：243/243 tests，157949 asserts。
- Web 无敌模式压力验收：180 敌人、120 帧；玩家、敌兵的行走与待机帧均被采样，SwiftShader 约 4.9 FPS。此数字不代表真机 GPU 性能。
- 新的步兵攻击衣装与骑乘层组合目前只通过离线 QA；未替代正式角色条带。
