# 文化来源与叙事边界

本文是《守望 · 永昌》公开仓库的文化来源索引。游戏运行不依赖本页；本页用于说明
设定、卡牌文案与图鉴中的 `source_ref` 指向哪些公开资料，以及哪些内容属于项目演绎。

赛事提供的原始全文、PDF、图片、OCR、缩略图、联系表和设计稿不随仓库分发。

## 叙事桥

游戏采用三段叙事：

1. **1386，宁村所**：汤和主持沿海卫所经略，宁村所建成。序章只写这一层。
2. **1558，王德移师宁村**：王德为策应温州府城移师宁村，次日于金岙殉国。
3. **1559，永昌堡**：王氏主持修筑永昌堡。正篇主角王陆（阿六）是虚构守灯乡勇。

可写的最硬关系是：

> 洪武十九年，汤和筑宁村所。嘉靖三十七年，王德移师宁村策应，次日殉国于金岙。
> 翌年，王氏筑永昌堡。

不得写成“汤和筑永昌堡”。永昌堡内的“东瓯王庙”祀汉东瓯王驺摇，不是宁村汤和庙，
也不能当作汤和与永昌堡的直接关系。

## 分类规则

游戏内每条剧情、卡牌与图鉴条目都带 `category` 和 `source_ref`：

- **史实**：有公开史料、地方志或文博机构页面直接支撑。
- **制度**：卫所、屯田、乡兵、筑城等制度性推断，不冒充单句史料。
- **民俗**：汤和信俗、中元祭、拦街福、拼字龙灯等活态传承。
- **演绎**：王陆、六种守夜阵位、灯火风险收益、龙鳞清屏、滩涂夜袭等游戏创作。

## 空间转译

永昌堡公开资料存在尺寸差异：南北有 757 米与 738.3 米两种口径，东西有 449 米与
445.4 米两种口径；桥梁也有 11 座与 5 座石桥的不同统计范围。游戏并列保留这些差异，
不把比例压缩后的地图当成测绘数据。

三张地图只保证“城墙、双渠、街坊、桥头”的相对拓扑。具体街坊数量、房屋位置、
敌台间距、出生带与灯火点位属于演绎。
