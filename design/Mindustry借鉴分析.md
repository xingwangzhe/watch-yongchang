# Mindustry 借鉴分析 —— 把"经营塔防"做实

> 调研日期 2026-11-22 ｜ 来源：Mindustry 官网、Steam 商店页、官方 Wiki（版本 160.7）
> 目的：解决当前《守望·永昌》GDD 中"建筑经营偏被动（只产资源、不参与战斗）"的弱点。

---

## 1. Mindustry 的核心洞察

官方定位：**工厂建设 + 塔防 + 即时战略**的开放式工厂管理游戏。其独特之处不是"有塔也有工厂"，而是：

> **炮塔火力 = 采矿 + 加工 + 运输 + 供电 + 冷却 的链式结果。**

- **供弹（ItemTurret）**：炮塔吃物品弹药（铜/石墨/钍），需传送带送入；有内部弹容，断供即停火；错误物品会堵线，需 Sorter/Router 控流。
- **供电（PowerTurret）**：需接入电网（Power Node→发电机/电池），电力不足降射速或停火。
- **冷却（Coolant）**：高级炮塔需低温液（Cryofluid）带走热量，否则过热停火。
- **物流层级极丰富**：物品传送带（5 级）、Duct、液体管道（含泵/储罐）、Payload 货运、单位货运；分拣/桥接/过载闸一应俱全。
- **单位链**：地面/空中/海上工厂 → Reconstructor（加法/乘法/指数/四次重构）升级单位 → 可自动管基地或攻敌基地。这与我们"2 合 1 升星"高度同构，验证了暴兵合成方向。
- **双向目标**：守核心 + 用单位攻占敌方基地，与我们"守城堡 + 推据点"一致。

**一句话**：Mindustry 把"经营"变成了战斗的一部分——你不是在塔防旁边种田，你是在**用物流养活防线**。

## 2. 与我们现状的差距

| 维度 | 我们 v0.1 | Mindustry | 差距 |
|---|---|---|---|
| 建筑作用 | 被动产粮/银，与塔防脱钩 | 采矿→加工→运输→供弹，直接决定火力 | 经营与战斗割裂 |
| 防御塔 | 造了就能打，没有消耗 | 吃弹药/电力/冷却，断供停火 | 塔缺乏脆弱性与深度 |
| 玩家决策 | 造什么塔、放哪里 | 还要设计补给线、分拣、扩容 | 策略层次偏薄 |
| 失败方式 | 城堡血量归零 | 物流被切断→防线瘫痪→核心被破 | 失败原因单一 |

## 3. 借鉴方案（文化转译 + 16 天可落地）

**关键原则**：不照搬传送带（明代背景会违和），而是把"物流链"转译成**水乡漕运/驿道递运**，既符合文化又保留机制内核。

| Mindustry 机制 | 我们文化转译 | 落地形态 |
|---|---|---|
| 传送带供弹 | **递运铺 / 驿道补给线** | 军械坊产"箭支/火药"，经递运路线送入炮塔；断供停火 |
| 电网供电 | **烽火台接力网络** | 高级塔（火铳台/投石机）需连入烽火台覆盖网，无覆盖降射速 |
| 冷却液 | **水渠 / 冰窖**（水乡主题） | 火铳台持续射击积热，需水渠降温，过热停火 |
| 分拣/路由 | **粮道岔口**（简化） | MVP 不做复杂分拣，固定补给线即可 |
| Reconstructor 升星 | 已有"2 合 1 升星" | 保留，方向已被验证 |
| 采矿→加工 | **市集/粮仓 → 军械坊** | 新增加工层，把原料变弹药 |

### 分层落地（控制 16 天风险）

- **第一层（必做，MVP）**：炮塔**消耗弹药**。军械坊产弹药，塔与军械坊相邻/在补给范围内即可供弹；断供停火。1 张 CSV 加 `ammo_type`/`ammo_per_shot` 即可实现，成本极低、收益极大。
- **第二层（强烈建议）**：烽火台覆盖网 = 电力网。高级塔必须覆盖，制造"先铺网再布塔"的策略。
- **第三层（有余力）**：水渠冷却 + 可视化补给线（在地面画出驿道）。视觉上最有 Mindustry 味道，但工作量最大。

## 4. 对主题契合的加分

- "守"不再只是摆塔，而是**守护整条补给链**——倭寇可袭击粮道，呼应历史上永昌堡"军民两用、耕读传家"的 self-sufficient 特质。
- "寓兵于民"制度（汤和史料）恰好是"生产与战斗一体"的历史原型，物流塔防因此有了文化合法性。
- 补给线被切断→防线瘫痪→重新组织，形成「守望相助」的叙事张力。

## 5. 结论

**采纳第一层 + 第二层**，第三层视时间决定。用最低成本把"轻建筑经营"升级为"物流养防线"，使 GDD 从"塔防+种田"进化为真正的"经营塔防"，同时保持文化主题与 16 天工期可控。
