# 《守望 · 永昌》肉鸽地图重设计方案

> 版本：2026-11-23
> 目标：把三张地图从“同一地面的色调/参数变体”改成有固定边界、真实结构、可读路线、桥头瓶颈与实时小地图的空间关卡。
> 约束：Godot 4.7.2-stable / GDScript / GUT 9.7.1；16 分钟单局；鼠标长按攻击；每 120 秒军市；最多 3 名 CharacterForge 佣兵；460 敌人上限；不恢复旧兵种目录；不改 CharacterForge 外观。
> 资料依据：`docs/06-资料文本化/地图空间资料索引.md`。

---

## 1. 设计目标

1. **空间先于数值**：玩家先感受到“这里是一座堡、一条街、一片滩涂”，再感受到敌速、密度、灯油差异。
2. **路线可读**：主环线、桥头、城门、街角在画面和小地图上都能被快速识别。
3. **瓶颈有代价**：桥面与门洞让玩家获得火力集中优势，也让敌人形成压力；不是单纯装饰。
4. **受控变化**：固定拓扑 + 出生带/精英路线/事件点的变化，避免全随机地形导致不可读。
5. **性能可守**：小怪走数据数组 + `MultiMeshInstance2D`，空间哈希 64px，寻路不逐敌 A*。

---

## 2. 从参考研究得到的四条规则

| 规则 | 参考 | 在本项目的执行 |
|---|---|---|
| 预制骨架 + 受控变化 | Hopoo Games 谈《Risk of Rain 2》 | 三图固定墙/水/桥/门；出生带与精英路线变化 |
| 纯随机是坏的 | iLLOGIKA《Rogue-like and Level Design》 | 所有出生带从玩家出生点可达；道路不被建筑覆盖；数据可测试 |
| 可读性优先 | Brendon Chung《Level Design: Readability》 | 水/桥/墙/道路强对比；地标固定色；小地图不做假装饰 |
| 入口/出口就是平衡 | Cogmind《Roguelike Level Design》 | 城门、桥头、玩家出生点是固定骨架；敌人从外围进入 |

补充：Hades 的白盒经验说明“每个生物群系要有明确战斗目标”，因此三图分别承担 **回环 / 瓶颈 / 交火口** 三种战斗语法。

## 3. 单局节奏（16 分钟）

| 时间 | 目标 | 地图行为 | 玩家决策 |
|---|---|---|---|
| 00:00–03:00 | 学会路线 | 只开放主环线与最近出生带；敌人从 1–2 个方向来 | 记住桥/门/主街，建立第一套走位 |
| 03:00–07:00 | 建立 Build | 侧环线打开；精英从远侧出生带进入 | 是否绕远拿经验/灯油，是否守桥 |
| 07:00–11:00 | 压力测试 | 多方向出生带同时启用；桥头与街角出现密集波 | 选择“卡桥”还是“拉出走廊” |
| 11:00–14:30 | 风险收益 | 灯油下降；远侧高风险点位刷新密集敌人 | 是否离开主环线取资源 |
| 14:30–16:00 | Boss 与收束 | Boss 从主门/主桥进入；出生带向玩家压缩 | 用桥头/门洞集中火力，保留龙灯清屏 |

设计原则：**前 3 分钟不惩罚迷路，中段开始惩罚贪路线，末段奖励提前选好的桥头**。

军市与地图节奏绑定：02:00 第一次开市时玩家已认识主环线，可用铜钱补一件兵器；
06:00–10:00 的军市用于决定“守桥还是拉走廊”的佣兵编成；14:30 前最后一次开市应让玩家
在 Boss 前补足远程/支援位，而不是无脑堆伤害。

## 4. 地图语法

### 4.1 五种空间构件

| 构件 | 作用 | 画面/小地图表现 |
|---|---|---|
| 主环线 | 玩家默认移动骨架，保证不会走进死路 | 连续道路；小地图亮色线 |
| 侧环线 | 风险收益：绕远换经验、灯油、精英 | 较窄道路/桥；小地图次级线 |
| 瓶颈 | 桥面、门洞、街角；集中火力与敌人压力 | 桥面木色、门洞金色、街角阴影 |
| 口袋 | 三面墙/水，短时可守但容易被围 | 小地图凹形结构 |
| 出生带 | 敌人进入战场的固定带，不围绕玩家圆形刷新 | 地图边缘/城门外的折线 |

### 4.2 禁止项

- 建筑压住主街、环墙路、桥头或出生带。
- 出生带穿水、穿墙、穿闭合建筑。
- 玩家出生点落在水面、墙内或不可达口袋。
- 用纯色调变化冒充地图差异。
- 小地图显示不存在的道路、建筑或地标。

## 5. 三张地图

### 5.1 滩涂夜（Tideland）

- **世界**：120×84 格，开放海岸滩涂。
- **真实意象**：永昌堡外、潮沟、盐坂、旧海塘、外海。
- **战斗语法**：开放式回环。两条潮沟把战场切成三块，桥面形成回环；盐坂与海塘提供天然遮挡。
- **主环线**：北堤 → 中部土路 → 南侧海塘路 → 东西两侧回环。
- **瓶颈**：潮沟桥（6 组）、旧海塘缺口。
- **风险收益**：外海侧鱼篓/渔船点位靠近出生带，资源多但回撤路线长。
- **小地图**：大面积沙色/泥色，潮沟为深青色折线，桥为木色短杠。
- **定位**：教学图，但仍要求玩家理解“桥是回环的一部分”，不是纯空地。

### 5.2 水门夜潮（Watergate）

- **世界**：96×160 格，南北长、东西窄。
- **真实意象**：永昌堡护城河、两条南北水渠、4 陆门、4 水门、12 敌台。
- **战斗语法**：多岛 + 桥头瓶颈。护城河与双渠把战场切成外堤、城墙带、内城三圈；每座桥都是可守点。
- **主环线**：南门/北门中轴 → 内城十字路 → 东西陆门 → 环墙路。
- **瓶颈**：四座陆门、四座水门、六座渠桥、四座护城河桥。
- **敌台节奏**：12 座敌台沿墙分布，形成“墙—台—门”的边界节奏；敌台本身是视觉地标与火力参照。
- **风险收益**：外堤出生带数量多，内城资源密度高；玩家可以选择守门，也可以出城清远侧出生带。
- **小地图**：外圈护城河深青、双渠纵向贯穿、城门金色菱形、水门浅青方块、桥木色。
- **定位**：主推图，最能表达“守城”的空间压力。

### 5.3 十字街（Crossstreet）

- **世界**：96×160 格，堡内街坊。
- **真实意象**：双渠夹街坊、十字主街、横巷、沿渠铺面。
- **战斗语法**：密集交火口。两条南北渠把街坊夹成狭长块；十字主街 + 四条横巷形成多个可切换的火力口。
- **主环线**：南北主街 → 十字街心 → 东西横街 → 沿渠巷。
- **瓶颈**：十座渠桥、四座陆门、四座水门、街角与巷口。
- **风险收益**：街坊内部资源密、退路短；主街视野好但暴露；沿渠巷适合绕后。
- **小地图**：街坊深褐块、道路亮灰、渠道深青、桥木色；十字街心为金色地标。
- **定位**：高密度图，强调“在窄巷里把敌人拉成线”，而不是靠更大数值。

## 6. 出生带与寻路

### 6.1 出生带规则

- 每个地图 7–10 条折线出生带，分布在外围、城门、桥头与内城远侧。
- 出生带点必须满足：
  1. `MapLayout.is_point_walkable(point, 14)`；
  2. 从玩家出生点做 4 邻域 BFS 可达；
  3. 与玩家距离优先落在 720–1500px，过远点作为后备。
- 不再围绕玩家画圆刷怪；玩家站在桥头时，敌人会从桥的另一端与侧路进入。

### 6.2 寻路

- 玩家与敌人共用 `MapLayout` 的碰撞格。
- 敌人优先在近距离（190px）直追；超出后读取玩家位置的 **BFS 流场**。
- 流场每 0.30 秒或玩家跨格时重建；4 邻域保证不穿墙角，8 方向采样时检查两个正交邻格。
- 不使用逐敌 A*；460 敌人共享一张距离场。
- 弹道用 `is_segment_wall_blocked` 检测墙体；水域阻挡移动但不挡弹道（箭可过水），由桥/墙决定射击线。

### 6.3 刷怪与清理

- 小怪数据数组；渲染按敌人类型合批 `MultiMesh`。
- 空间哈希 64px 用于伤害/拾取/最近敌人查询。
- 死亡敌人延迟清理，避免遍历中删除。

## 7. 小地图信息层级

小地图是右上角 232×174 的实时渲染，不是装饰图。

| 层级 | 内容 | 视觉 |
|---|---|---|
| 底图 | 地形、道路、水、桥、建筑、墙 | 1px/格，最近邻放大 |
| 地标 | 城门、水门、桥头、街心、潮沟 | 金色菱形/方块、浅青水点 |
| 玩家 | 位置 + 朝向 | 亮金点 + 短线 |
| 敌人 | 普通/精英/Boss | 红点/橙方块/大橙点 |
| 拾取物 | 经验、灯油、治疗、龙鳞 | 黄/橙/绿/彩色小点 |
| 镜头 | 当前视野框 | 半透明金线 |
| 方向 | 北向标记 | 右上角罗盘 |

刷新间隔 75ms；只读 `Battlefield` 的只读数据，不反向修改战斗。

HUD 重排：击杀/军功从右上角 `x=1016` 左移到 `x=782`，宽度 212；小地图固定在 `(1014, 14)`，尺寸 `232×174`。二者不重叠。

## 8. 性能预算

| 项 | 预算 | 当前实现 |
|---|---|---|
| 地图层 | 3 层 `TileMapLayer`（地形/建筑/道具） | `MapRenderer` |
| 地面 | 固定地图，不平铺 512px 循环贴图 | `maps.json` 逐格绘制 |
| 敌人 | 460 上限，按类型合批 | `MultiMeshInstance2D` |
| 空间查询 | 64px 哈希 | `Battlefield.spatial` |
| 寻路 | 共享 BFS 流场，30Hz 重建 | `MapLayout.ensure_flow_field` |
| 小地图 | 底图一次生成，动态点每 75ms | `RunMinimap` |

压力场景仍以 460 敌人测试；绝对 FPS 必须在正常唤醒的原生桌面/Windows 复测，不能用当前远程桌面 1 FPS 的读数下结论。

## 9. 后续扩展

1. **城门开关**：Boss 前关闭两座侧门，强制玩家选主桥；需保证出生带仍连通。
2. **潮汐事件**：滩涂涨潮临时淹没低地，改变桥面价值；需要新的水域/桥面动态层。
3. **摊位破坏**：十字街铺面可破坏，打开新巷口；需要建筑格与道具格的运行时替换。
4. **精英路线**：精英沿固定侧环线进入，给玩家“预判路线”的空间。
5. **小地图标记**：灯油/龙鳞/精英只在地标附近显示，避免信息过载。

---

## 10. 验收标准

- 三图均有固定世界尺寸、三层 `TileMapLayer` 与小地图底图。
- 水门夜潮：4 陆门、4 水门、12 敌台、两条南北渠；十字街：双渠、十字主街、60+ 街坊。
- 道路/广场不与建筑矩形相交。
- 所有出生带点可走，且从玩家出生点 BFS 可达。
- 玩家、敌人、弹道受墙体约束；水域不可走，桥面可走。
- 相机被限制在地图边界内。
- HUD 小地图不与击杀/军功重叠，且实时显示玩家、敌人、拾取物、镜头框。
- 全量 GUT 通过；三图各留一张实机截图。
