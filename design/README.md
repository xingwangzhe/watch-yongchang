## CSV 导入 Godot 建议

- 用 `FileAccess.open()` + `get_csv_line()` 解析，或安装 CSV 导入插件生成 `Resource`。
- 字段中的中文可直接在 GDScript 用 `tr()` 做多语言；英雄技能与合成倍率等常量可放在 `DataDB` autoload 中。
- 数值为初始基线，调平衡时只改 CSV，不改逻辑代码。
