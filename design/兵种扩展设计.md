## 1. 《米拉奇战记》兵种体系调研

### 1.1 数量口径

检索到的公开资料存在两个统计口径，记录如下，不在本项目内部做唯一化断言：

- **49 种口径**（按阶位分类的可数清单）：
  - 一阶低价 6：新兵、老兵、武士、木乃伊、剑兵、忍者
  - 一阶高价 6：修女、野猪战士、战斗猫、重弩兵、骷髅兵、重甲剑兵
  - 二阶低价 7：武僧、长枪兵、男爵、野人、骑兵、半人马、弓箭手
  - 二阶高价 6：勇者、不朽者、大熊、魔法师、黄金骑兵、铁甲骑士
  - 三阶低价 7：鹰身人、骑士安全官、狼人、巨斧、石头人、执行官、祭司
  - 三阶高价 5：幽灵刺客、陆槽长、龙人、影舞者、侍大将
  - 四阶 12：大领主、大法师、圣光骑士、审判者、黑骑士、拳霸、龙枪骑士、恐惧魔王、先知、虎鲸公爵/伯爵、万骑长、总大将
- **57 种口径**：40 个直播间默认兵种 + 17 个可替换兵种。

### 1.2 阶位与携带

- 兵种按 1–4 阶分层，阶位越高，人口占用、费用、战力同步上升。
- 主流携带方案为 15 个槽位，按 6 / 5 / 3 / 1 分配，形成"低阶铺场 + 中阶主力 + 高阶决胜"的金字塔。
- 2 合 1 升星（重构/合成）是暴兵流的核心爽点，高阶单位合成收益递减但绝对战力仍高。

### 1.3 克制维度

社区攻略反复出现的判定轴：

1. **甲种**：轻甲 / 重甲，决定物理与法术/穿甲的实际伤害。
2. **职能**：清兵（AOE）、反手（单体高伤）、远程、高速突袭、高血前排。
3. **特殊**：召唤、辅助光环、控制、范围伤害、隐匿。
4. **站位**：远程怕突脸、枪方阵怕绕后、重甲怕持续消耗。

### 1.4 对《守望·永昌》的启示

| 米拉奇机制 | 本项目转译 |
|---|---|
| 40+ 兵种大池 + 15 槽携带 | 60 种池子 + 15 槽出战，保证每局构筑差异 |
| 四阶金字塔 | 一阶"民"、二阶"军"、三阶"将"、四阶"王/神" |
| 轻甲/重甲二分 | 扩展为 none / light / medium / heavy / energy 五甲种 |
| 清兵 vs 反手 | `role_tags` 显式标注 clear / anti_heavy / rush 等标签，克制定表化 |
| 升星重构 | `star2_mult` / `star3_mult` 保留，按阶位递减（2.2→1.6），避免四阶滚雪球 |

## 2. 设计原则

### 2.1 四轴定位

每个兵种由四个轴唯一确定，避免"换皮重复"：

1. **阶位 / 人口**：tier 1–4，pop = 1 / 2 / 4 / 8。
2. **甲种**：`armor_type`。
3. **职能标签**：`role_tags`，分号分隔，可多标签。
4. **文化来源**：`culture_source`，必须能追溯到赛事资料包或官方创作方向。

### 2.2 甲种定义

| 甲种 | 定位 | 主要弱点 |
|---|---|---|
| `none` | 无甲、脆皮远程/辅助 | 一切近身与突袭 |
| `light` | 轻甲，机动单位 | 穿甲、范围伤害 |
| `medium` | 中甲，正规军 | 反重甲、控制 |
| `heavy` | 重甲，将级单位 | 穿甲、持续消耗、火焰 |
| `energy` | 能量体，未来/神性单位 | 反能量、控制链 |

### 2.3 职能标签（role_tags）

| 标签 | 含义 |
|---|---|
| `melee` / `ranged` / `siege` | 近战 / 远程 / 攻城 |
| `tank` / `shield` / `formation` | 承伤 / 护盾 / 阵列加成 |
| `clear` / `group` | 清兵 / 群体伤害 |
| `anti_light` / `anti_heavy` / `anti_cavalry` / `pierce` | 定向克制 |
| `rush` / `cavalry` / `raider` | 突袭 / 骑兵 / 绕后 |
| `control` / `detect` / `stealth` | 控制 / 侦测 / 隐匿 |
| `heal` / `support` / `summon` / `command` | 辅助类 |
| `economy` / `logistics` / `repair` / `build` / `trap` | 经营类，与补给链系统联动 |
| `culture` / `elemental` / `vengeance` / `ethereal` | 文化/属性/遗恨/神性特殊机制 |

### 2.4 数值带宽

| 阶位 | food_cost | spawn_cd | hp | damage | star2 / star3 |
|---|---|---|---|---|---|
| 一阶 | 10–22 | 1.0–1.8 | 70–200 | 6–30 | 2.2 / 2.4 |
| 二阶 | 23–36 | 1.7–2.6 | 100–300 | 12–56 | 2.0 / 2.2 |
| 三阶 | 50–78 | 3.5–5.0 | 180–620 | 20–88 | 1.8 / 2.0 |
| 四阶 | 100–145 | 6.2–9.5 | 700–2400 | 90–230 | 1.6 / 1.8 |

高阶合成倍率递减是刻意设计：防止四阶单位经二次合成后单局碾压，同时保留低阶"暴兵→合成"的成长感。

## 3. 携带与解锁规则

### 3.1 出战槽位

- 每局从 60 种中选择 **15 种**出战。
- 槽位配比固定：**一阶 6 / 二阶 5 / 三阶 3 / 四阶 1**。
- 每阶内部可自由替换，形成"选牌"体验。
- 总人口上限随章节提升：初始 24 → 最终 40。满配 15 槽的理论人口为 6×1 + 5×2 + 3×4 + 1×8 = 36，因此终局可全槽满配，前期必须做取舍。

### 3.2 章节解锁

| 章节 | 创作方向 | 解锁阶位 | 新增池 |
|---|---|---|---|
| 第 1 章 | 抗倭叙事 | 一阶 | 乡勇、民壮、弓手、藤牌、长枪、狼筅 |
| 第 2 章 | 城堡防御 | 二阶 | 卫所军、强弩手、守备、石匠、濠手 |
| 第 3 章 | 家族传承 | 三阶 | 王氏家将、王叔杲、学士、进士 |
| 第 4 章 | 节庆巡游 | 三阶 | 龙灯队、五龙队、龙灯首、天下太平阵 |
| 第 5 章 | 水乡生活 | 二阶 | 船夫、水师、伙夫、耕户、书院生员 |
| 第 6 章 | 未来想象 | 四阶 | 机械倭、AI守望者、时光舟、东瓯王 |

四阶"历史人物"类（汤和、王沛、王德、戚继光等）按章节进度逐步解锁，作为通关奖励而非开局可得。

## 5. 克制关系速查

### 5.1 标签级克制

| 攻击方标签 | 有效目标 | 说明 |
|---|---|---|
| `anti_light` | none / light | 低费清场，克制轻甲铺场 |
| `anti_heavy` / `pierce` | medium / heavy | 强弩、火铳、神机营 |
| `anti_cavalry` | `cavalry` / `rush` | 长枪、狼筅、拒马 |
| `ranged` | 近战低机动 | 但被 `rush` 近身反制 |
| `rush` / `cavalry` | ranged / support / economy | 绕后袭扰补给线 |
| `control` | `rush` / `formation` | 打断冲锋与阵列 |
| `detect` | `stealth` | 巡城卒、巡检司役、游骑 |
| `fire` / `group` | `formation` / 密集阵 | 火炮、神机营、五龙队 |
| `build` / `repair` / `logistics` | 建筑与补给设施 | 与 Mindustry 式补给链联动 |

### 5.2 典型闭环

```
弓手(ranged) → 克 → 乡勇(light melee)
      ↑                    ↓
   被 rush 克         被 shield/tank 挡
      ↑                    ↓
长枪(anti_cavalry) ← 克 ← 骑兵(cavalry)
```

设计意图：任何单一兵种都存在两条以上的解，避免"最强兵种"固化。

## 7. Godot 集成建议

### 7.1 数据结构

`units.csv` 新增 6 个字段：`tier`、`pop`、`armor_type`、`role_tags`、`gameplay_hook`、`counters/countered_by` 改为标签制。

```gdscript
class UnitDef extends Resource:
    var id: StringName
    var name: String
    var tier: int
    var pop: int
    var armor_type: StringName
    var role_tags: PackedStringArray
    var counters: PackedStringArray
    var countered_by: PackedStringArray
    var gameplay_hook: String
```

### 7.2 解析注意

- `role_tags` / `counters` / `countered_by` 用英文分号 `;` 分隔，禁止使用逗号（CSV 分隔符）。
- CSV 无 BOM，可直接 `FileAccess.open()` + `get_csv_line()`。
- 相克判定走 `DataDB.query_counter(attacker_tags, defender_tags)`，不要在单位脚本里硬编码 if-else。

### 7.3 15 槽 UI

- 选牌界面按 4 个阶位分栏，每栏可选数量分别锁为 6 / 5 / 3 / 1。
- 出兵面板显示当前人口 / 上限，超限时禁止放置。
- 兵种图鉴以 `culture_source` 作为分组键，与文化事件卡共用索引。
