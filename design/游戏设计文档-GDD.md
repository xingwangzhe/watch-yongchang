# 《守望 · 永昌》游戏设计大纲

> 类型：Vampire Survivors-like / 割草生存 Roguelite
> 版本：v0.5（2026-11-24，军市与义师：局内铜钱商店 + CharacterForge 佣兵 + Jeff-FX 友军攻击层）
> 引擎：Godot 4.7.2-stable（版本锁定于 `game/.godot-version`），2D，GDScript；
> 性能热点允许 C++ GDExtension，但必须保留纯 GDScript 回退并覆盖 Windows 构建
> 单局时长：16 分钟；目标平台：Windows / Linux 桌面，1280×720 起

---

## 1. 一句话概念

**你是永昌堡外最后一盏灯。**

倭寇围城的夜里，你孤身守在城外滩涂与街巷之间，用鼠标瞄准、长按左键挥刀、放箭、开铳，
在潮水般的敌人中撑到黎明；每一次升级都在“兵器、阵法、灯火”之间做取舍。

### 1.1 历史三段结构

| 段落 | 时间 | 地点 | 可操作角色 | 叙事功能 |
|---|---|---|---|---|
| 序章 | 1386 | 宁村所 | 汤和 | 点第一盏望海灯、定所城界桩、立乡兵旗；交代“寓兵于民”与沿海卫所网络 |
| 正篇 | 1559 | 永昌堡 | 虚构守灯乡勇**王陆 / 阿六**（单一主角，六种守夜阵位） | 十六分钟守灯生存；王德 1558 移师宁村、殉国金岙作为前史 |
| 尾声 | 2026 | 龙湾 / 汤和信俗 | 无操作 | 汤和诞辰七百周年，五龙拼“天下太平”，灯火从 1386 传到今天 |

**史实桥**：洪武十九年汤和筑宁村所 → 嘉靖三十七年四月十九日王德移师宁村策应 →
四月二十日王德殉国金岙 → 王氏筑永昌堡 → 1559 守灯人。

**红线**：汤和是序章主角，不是 1559 的活人主角；不得写“汤和建永昌堡”。
永昌堡东瓯王庙祀汉东瓯王驺摇，与宁村汤和庙不是同一座庙。

## 2. 主题落点：守 · 望

- **守**：不是造塔守城，而是**人守在人海里**。玩家是城墙外的第一道防线。
- **望**：望楼灯是核心资源。灯火越亮，视野与拾取范围越大，但会吸引更多敌人；
  灯油耗尽则进入“摸黑”高风险高收益状态。
- **文化**：永昌堡、十三进士、王沛/王德乡兵、拼字龙灯、汤和信俗、拦街福。
  文化不是贴图，而是玩法：阵法、灯火、龙灯拼字、百家宴士气。

## 3. 核心循环

### 3.1 30 秒循环

移动躲包围 → 鼠标瞄准并按住左键攻击 → 拾取铜钱/灯油 → 升级三选一 / 军市购物 →
带佣兵继续推进。

### 3.2 16 分钟单局

| 时间 | 事件 | 目的 |
|---|---|---|
| 0:00 | 夜袭开始，初始兵器 | 教学：移动、拾取、升级 |
| 2:00 | 第一波倭寇斥候 | 建立压力 |
| 4:00 | 藤牌武士小队 | 检验破甲需求 |
| 6:00 | 火枪倭出现 | 远程威胁，要求走位 |
| 8:00 | 精英“倭将” | 第一个构筑检查点 |
| 10:00 | 灯油事件：油尽/添油二选一 | 风险收益抉择 |
| 12:00 | 混编潮 + 旗手 | 士气与清屏能力检验 |
| 14:00 | 第二倭将 + 大名先锋 | 终局前压力 |
| 15:30 | 大名入场 | Boss 战 |
| 16:00 | 黎明钟响 | 结算、解锁 |

每 2:00 在升级结算之后开一次“灯下军市”，暂停战斗，三格货摊分别保证兵器、装备与
佣兵（佣兵满编后由装备/补给替代）；购买或重掷消耗局内铜钱，关闭后继续计时。

### 3.3 跨局循环

军功 → 解锁王陆的守夜阵位/地图 → 银两 → 永久小加成 → 更高难度 → 图鉴与剧情碎片。

## 4. 操作

| 输入 | 行为 |
|---|---|
| WASD / 方向键 | 巡灯步，八向移动 |
| 鼠标位置 | 控制攻击方向与角色朝向 |
| 鼠标左键按住 | 兵器按各自冷却持续攻击；松开立即停手 |
| 空格 | 灯影步冲刺（短无敌，冷却 3s，带残影） |
| 1 / 2 / 3 | 升级三选一 |
| 1 / 2 / 3 | 军市购买；R 重掷；Enter 继续 |
| Esc | 暂停 |
| C | 打开双堡图鉴 |
| 触屏左下摇杆 | 巡灯，八向移动 |
| 触屏右下按键 | 灯影步 |

**原则**：鼠标决定攻击扇面与突刺方向，长按左键连续出手，不要求重复点击。
移动时精灵按水平速度镜像；攻击时朝向跟随鼠标，避免向左移动仍面向右侧。
移动不是无意义的跑位，而是“巡灯”：沿堡墙、水门与街巷保持灯火，亮处更安全也更容易
被敌人发现，暗处经验更高。触屏设备自动显示“巡灯”摇杆与“灯影步”按键，卡牌可直接点选。

## 5. 局内成长

### 5.1 等级与经验

- 单局 1–30 级；经验来源：军功袋（小/中/大）、精英掉落、灯油罐。
- 经验曲线：`need(n) = 5 + 4n + 0.35n²`，30 级约 16 分钟。
- 升级立即暂停，给出 3 张卡：属性 / 技能 / 事件，另混入新兵器、兵器升级、
  被动与补给；抽取时首张优先攻防成长，第二张保证构筑或事件，第三张保留稀有度博弈。
- 满级兵器不再出现在卡池；卡池按权重抽取，避免死卡。
- 卡面显示卡族、阶数、品第、效果摘要、堡志文化说明、来源分类（史实/制度/民俗/演绎）
  与可追溯出处；鼠标悬停可读完整来源。

### 5.2 构筑槽位

- 6 个兵器槽 + 6 个被动槽。
- 兵器最高 5 级；被动最高 5 级。
- 进化：**兵器 5 级 + 指定被动 3 级** → 升级三选一出现进化卡。

### 5.3 卡池规模与文化装饰

- 新构筑卡池：50 属性 + 38 技能 + 22 事件 = 110 张；可重复升级条目 452 个。
- 加上兵器、被动、进化、补给后，运行期展示池实测 546 项。
- 规模对照：Brotato 有 64 个 level-up upgrades；VS base game 有 21 个被动
  （17 个普通被动）与 6 兵器槽 + 6 被动槽。本作卡池在“可选项与升级阶”上不低于两者。
- 每张卡必须有中英名称、中英描述、中英文化说明、图标、品第、最大阶数、效果数组、
  来源分类与 `source_ref`；缺一项即测试失败。
- 图标来自 game-icons.net，共 65 个 SVG，登记作者、原图链接与 CC BY 3.0；
  卡族颜色：属性=青、技能=朱、事件=紫，稀有度用边框与品第文字区分。
- 文化不是独立图鉴页，而是卡牌效果本身：甲片来自城墙夹层旧甲，灯油对应永昌守夜，
  潮汐阵、渔网、海雾、龙灯、百家宴、汤和庙钟都直接改变战斗参数或事件。
- 主动技法覆盖齐射、灯火爆发、迟滞、灼烧、震晕、连锁、回复、收魂、护盾、反伤、
  饮血与灯影步；敌人具备减速、灼烧、眩晕状态，拾取物可被收魂牵引。

### 5.4 灯火（本作差异化）

- 初始灯火半径随灯油比例在 132–252px 间变化；默认每 30s 消耗 1 格，共 6 格起。
- 灯火越亮：拾取半径 +、暴击 +、敌人索敌范围 +（更危险）。
- 灯油为 0：灯火半径缩到 120px，敌人移速 +20%，经验 +50%，暴击 +15%，可主动“摸黑”刷级。
- 拾取灯油罐回复 1 格；精英必掉补给，Boss 掉大药包。

### 5.5 军市与义师佣兵

- **货币分离**：`merit` 仍是结算军功与解锁进度；军市只用局内 `run_coin`（铜钱）。
  击杀按敌人经验值折算铜钱，精英 ×2，Boss 额外给 120；`gold_mult` 同时影响两者。
- **开市节奏**：每 120 秒一次。升级三选一的优先级高于军市，必须先把 `_pending_levels`
  清空；军市打开时清空长按攻击、暂停战斗，关闭后从当前时间重新计算下一次开市。
- **货摊规则**：每摊 3 格，首格保证兵器（新兵器或升炼），第二格保证装备，第三格在
  佣兵未满 3 人时保证佣兵；其余空位从兵器/装备池补齐，池空时补伤药或灯油。
- **兵器**：新兵器受 6 槽限制；已有兵器最高 5 级，价格随等级递增。军市不替代升级卡，
  只提供用铜钱追赶构筑的第二条路径。
- **装备**：复用 12 件被动装备（磨刀石、绑腿、箭囊、五色纸、甲片、灯油、罗盘、
  火药、米粮、铜锣、伤药、家书），购买后立即 `_recompute_stats()`。
- **佣兵上限**：最多 3 名，不能重复购买同一人。佣兵作为战场友军存在，不占王陆的
  6 个兵器槽，也不进入选择页人物列表。
- **友军 AI**：跟随玩家，索敌半径 520px，仅在玩家 390px 范围内交战；近战走扇形/圆形
  伤害，远程走友军弹丸，支援型周期震退敌人并回血。友军精灵按水平移动镜像。
- **友军特效**：`attack_fx.json` 新增 `ally_attacks` 8 条，复用 Jeff-FX-forge 已导出的
  帧动画；总组合从玩家 24 + 敌兵 16 扩为再加佣兵 8，共 48 种。

#### 1559 佣兵文化边界

| 单位 | 类型 | 文化处理 |
|---|---|---|
| 义师枪兵 / 义师弓手 / 藤牌乡兵 | 乡兵 | 标 `制度`，按明代浙南乡兵器械与守巷方式解释 |
| 鸟铳手 | 火器乡兵 | 标 `史实`，说明鸟铳装填慢、近距破甲 |
| 令旗手 | 阵眼支援 | 标 `制度`，旗是集合点，不是法术塔 |
| 戚家军客兵 | 稀有客兵 | 标 `演绎`，只写戚继光抗倭体系与 1555 宁村行迹，不写他亲临 1559 永昌堡 |
| 王沛英魂 / 王德英魂 | 英雄单位 | 标 `民俗`，只作乡贤香火/英魂寄意；二人是前史人物，不复活、不亲临 1559 |

## 6. 主角与守夜阵位

正篇只有一名可操作人物：虚构守灯乡勇**王陆（乳名阿六）**。
选择页的六张卡不是六名人物，而是王陆换用的兵器与站法：

| 阵位 | 定位 | 初始兵器 | 被动 | 解锁 |
|---|---|---|---|---|
| 均衡位 | 均衡/新手 | 腰刀 | 绑腿（移速） | 初始 |
| 龙灯位 | 范围/信俗 | 龙灯 | 五色纸（范围） | 军功 350 |
| 藤牌位 | 守御/近战 | 藤牌 | 甲片（护甲） | 军功 700 |
| 火铳位 | 爆发/高风险 | 手铳 | 火药（暴击） | 军功 1100 |
| 远射位 | 远射/拾取 | 弓 | 箭囊（拾取） | 军功 1500 |
| 旗令位 | 号令/增益 | 长枪 | 铜锣（范围） | 军功 2000 |
| 汤和（仅序章） | 序章·筑所 | 长枪 | 磨刀石 | 序章固定角色，不进正篇池 |

阵位差异只做**初始兵器 + 1 个被动 + 基础数值偏移**，不做过长的独立技能树。

**角色边界**：1559 正篇始终由王陆出场；王沛、王德只在前史中出现，不作可操作人物。
汤和仅出现在 1386 序章与 2026 尾声纪念语境。正篇不得让汤和以活人身份登场，
也不得把宁村所与永昌堡写成同一座城。

## 10. 文化系统

- **拼字龙灯（已实现）**：五名倭将分别携带红/黄/蓝/绿/黑龙鳞；集齐后五龙穿场清屏。
- **双堡图鉴（已实现）**：局内 `C` 或主菜单打开，展示 1386 宁村所、1558 王德移师、1559 永昌堡。
- **卡牌堡志（已实现）**：属性、技能、事件卡各自带文化说明与来源分类；
  事件卡会即时改变战局并播放“灯下”叙事，不把文化做成无机制的静态文字。
- **触屏巡灯（已实现）**：左下巡灯摇杆与右下灯影步按键，使用同一套移动/冲刺逻辑。
- **十三进士（待扩展）**：计划每局随机 1 位进士残影提供祝福。

## 14. 技术方案

### 14.1 工程结构

```
game/
  project.godot
  scenes/        main_menu.tscn / prologue.tscn / character_select.tscn
                 run.tscn / codex.tscn / about.tscn
  scripts/
    autoload/    GameSettings / Locale / SaveSystem / AudioBus
    core/        data_loader / ground_texture
    actors/      run_game / battlefield / prologue
    ui/          hud / story_overlay / level_up / codex / character_select
  data/          weapons.json / enemies.json / waves.json / characters.json
  assets/        units / tiles / ui / audio / fonts
  tests/         unit (GUT) / balance (16-minute headless bot)
```

### 14.2 性能

- 目标：1280×720、400–460 敌人；先记录 GDScript 基线帧率，再决定是否迁移热点。
- 当前敌人为**数据数组 + 自绘**，碰撞查询走 64px 空间哈希；同屏上限 460。
- 460 敌人压力场景已用按贴图分组的 `MultiMesh` 批绘，draw calls 从 930 降到 14。
- 弹幕、经验袋与特效共用轻量数组，避免每帧创建节点。
- 若 400+ 敌人实测低于目标，再写 C++ GDExtension 宽相位查询，并保留 GDScript 回退。
- 当前桌面会话被限制到约 1 实际帧/秒（空场景同样），绝对 FPS 必须在正常唤醒的
  原生桌面与 Windows 复测，不能拿该环境结果验收性能。
- 所有生成用固定种子，便于复现与平衡测试。

### 14.3 数据驱动

- 兵器、敌人、波次、角色全部 JSON；改数值不改代码。
- 兵器行为用 `WeaponPattern` 枚举 + 参数（扇形角、弹速、穿透、冷却）。
- 波次表按秒配置：`{t, enemy, count, pattern, elite}`。

### 14.4 测试

- `gda script run res://tests/smoke.gd --project game`：启动、生成、升级、结算。
- 无头跑 16 分钟加速模拟：检查卡死、NaN、对象泄漏。
- 截图验收：主菜单、战斗、升级、Boss、结算、滚幕；结算见
  `docs/screenshots/game_2026-11-23/result_victory.png`。
