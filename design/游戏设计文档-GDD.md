# 《守望·永昌》游戏设计文档（GDD）

> 版本 v0.2 ｜ 2026-11-22 ｜ 面向 2026 开源游戏开发大赛（OSGJ）
> 主题：**守 · 望** ｜ 引擎：Godot 4.x（GDScript）｜ 类型：暴兵对推 + 塔防 + **物流经营** + 文化闯关

## 0. 一句话概念（Elevator Pitch）

> 一座明代海防城堡，十六天内抵御倭寇的轮番围攻。你一边在城墙上**筑塔布防**、在城内**营造市井**，一边**暴兵合成**乡勇与龙灯队沿三条水陆要道反向推平倭寇据点——守的是家园，望的是海那头的新世界。

**玩家幻想**：从"被动挨打的守城者"成长为"主动出击的城堡之主"。守与望不是两种玩法，而是同一场战役的两面。

## 1. 主题契合论证

| 主题字 | 玩法映射 | 文化映射 |
|---|---|---|
| **守** | 塔防、城墙维修、资源经营、防守波次 | 永昌堡的建筑与防御体系、抗倭历史 |
| **望** | 暴兵反向推塔、开拓据点、瞭望/科技解锁 | 汤和巡游的节庆向心力、水乡生活、未来想象 |

- 官方公布的 6 个创作方向（抗倭叙事 / 城堡防御 / 家族传承 / 节庆巡游 / 水乡生活 / 未来想象）**直接作为 6 个关卡章节**，使"主题—关卡—文化"三者一一对应，评奖时"文化传承创新奖"的契合度可被清晰论证。
- 命名备选：`守望·永昌`（主推）／`永昌守望录`／`一堡千年`／`望海·守望`。

## 2. 核心玩法循环（Core Loop）

```
   采粮银 → 军械坊造弹药 → 补给线送弹 → 炮塔开火  ← 守（物流养防线）
                                          ↑
   [波次开始]                       烽火台供电网
        │
        └→ 暴兵/合成 → 自动推进 → 推据点  ← 望
                                          │
        └──────→ 结算文化点/星级 ←── 守住城堡 & 摧毁据点 ┘
                         │
                   解锁下一章节/图鉴
```

**v0.2 关键变化**：塔不再"造了就能打"。**炮塔消耗弹药，弹药由军械坊经补给线送入**；断供即停火。经营从"背景种田"变为"防线存续的前提"——这是借鉴 Mindustry 的核心改动。

**单局节奏（约 5–8 分钟）**：
1. **筹备期（0–40s）**：布置粮仓/市集 → 军械坊 → 补给线 → 炮塔 → 烽火网，先建立"生产-供弹"闭环。
2. **第一波（40–100s）**：小规模倭寇探路，玩家开始暴兵并扩容弹药。
3. **压力期（100s–）**：多路线混编敌人 + 头目；敌寇可能袭扰补给线，需兼顾供弹与出兵。
4. **决胜**：摧毁敌方据点获胜；城堡血量归零失败；撑过全部波次按防守成绩结算。

**元循环**：章节星级 → 解锁 LOGO/建筑皮肤/兵种 → 图鉴收集（素材来自官方素材包）→ 回看文化事件卡。

## 3. 战场结构

- **视角**：横版 2D，固定镜头，横向卷动幅度小。
- **三路**：上（陆路·山道）／中（主道·城门）／下（水路·河道）。每路两端分别是玩家城堡与敌方据点。
- **单位**：出兵后**自动沿路推进**，遇敌自动交战（米拉奇战记式），玩家不直接操控单体——降低操作负担，把决策集中在"造什么、造多少、放哪里"。
- **建造格**：城堡侧有若干网格空地（塔位/建筑位），城墙上有固定塔基。
- **双向目标**：敌人推向城堡（塔防），我方推向据点（暴兵对推）。**两个胜负条件并存**，使"守"与"望"同时有意义。

```
 [我方城堡]  塔位·建筑位  ||  中路  ||  上路  ||  下路  ||  [倭寇据点]
   HP 1000       [格][格]  ──────────────────────────────>  HP 800
                 ↑ 玩家在这里造塔/造兵/升级
```

## 4. 系统详解

### 4.1 暴兵系统（核心爽点）

- **资源消耗**：出兵消耗 **粮草**，并占用 **兵力上限**。
- **合成进阶（米拉奇风味）**：场上/待命区中 **2 个同兵种同星级 → 自动合成 1 个高一星**单位，属性跳增。这是"暴兵"的爽点来源：先堆量，再质变成精锐。最高 3 星。
- **兵种与相克**（4 种基础 + 2 种文化特色）：

| 兵种 | 定位 | 克制 | 被克 | 文化来源 |
|---|---|---|---|---|
| 乡勇 | 便宜近战，铺量 | 火铳兵（贴脸） | 弓手 | 明代乡兵/民壮 |
| 弓手 | 远程，站桩输出 | 乡勇（慢） | 藤牌兵 | 城防弓弩 |
| 藤牌兵 | 高远程抗性，前排 | 弓手 | 火铳兵 | 明代藤牌抗倭战术 |
| 火铳兵 | 穿甲，破藤牌 | 藤牌兵 | 乡勇（近身） | 明代火器 |
| 龙灯队 | 范围伤害+全军士气/移速增益 | 群体 | —— | 拼字龙灯（非遗） |
| 进士 | 高费精英，附近友军获得暴击/减伤光环 | —— | —— | 永昌"十三进士" |

- **出兵操作**：点击兵种卡 → 点击目标路线出兵；可用快捷键 `1–6` 选兵、`Q/W/E` 选路。可长按连续出兵（暴兵手感）。
- **兵力上限**：随建筑"兵营"等级提升。

### 4.2 塔防系统（物流驱动 · v0.2）

| 塔 | 造价 | 弹药/供给 | 特点 | 文化来源 |
|---|---|---|---|---|
| 箭塔 | 低 | 消耗**箭支** | 单体速射，基础，弹药需求低 | 城墙箭楼 |
| 火铳台 | 中 | 消耗**火药** + 需在烽火网内 + 过热需水渠 | 穿甲，对藤牌/头目 | 火器 |
| 投石机 | 高 | 消耗**石弹** + 需在烽火网内 | 范围伤害，清群 | 城防器械 |
| 烽火台 | 中 | 无弹药（供能建筑） | 提供视野 + 供电覆盖 + 全塔攻速光环 | 烽火/瞭望（呼应"望"） |

- **断供停火**：每塔有内部弹容；弹药耗尽则停火，直到补给线送达。玩家必须维持"军械坊→补给→塔"的链条。
- **烽火供电网**：火铳台/投石机必须位于至少一座烽火台的覆盖范围内，否则射速 -50%；无覆盖的攻坚塔等同废塔。
- 每塔 3 级升级；同一塔位可替换；拆除返还部分资源。
- 塔只攻击**进入射程的敌方单位**，不攻击据点（避免挂机推塔）——据点只能靠暴兵推。
- **可选第三层（有余力）**：火铳台连续射击积热，需水渠降温，过热停火（水乡主题，见 4.4）。

### 4.3 补给线与建筑操作（经营核心 · v0.2）

- **操作**：拖拽放置到空地 / 点击升级 / 长按拆除；补给线用"从军械坊点选目标塔"连线生成（MVP 简化，不做自由绘制传送带）。

| 建筑 | 功能 | 文化来源 |
|---|---|---|
| 粮仓 | 持续产粮草（军械坊原料） | 水乡耕读 |
| 市集 | 持续产银两 | 水乡商贸 |
| **军械坊** | 消耗粮/银 → 产出箭支/火药/石弹（炮塔弹药） | 明代军械制造 |
| **递运铺** | 延长补给线射程，连接远处炮塔 | 驿道递运制度 |
| 兵营 | 提升兵力上限、缩短出兵冷却 | 卫所兵制 |
| 书院 | 解锁"进士"兵种、提升文化点获取 | 十三进士、家风家训 |
| 汤和祠 | 产"香火"，加速英雄技能 | 汤和信俗 |
| 烽火台 | 供电覆盖 + 视野 + 攻速光环（见 4.2） | 烽火/瞭望 |
| 城墙工坊 | 自动缓慢修复城堡 HP | 永昌堡城防 |

### 4.3.1 补给链规则（借鉴 Mindustry 的核心）

```
粮仓(粮) + 市集(银) ─→ 军械坊 ──补给线──→ 箭塔/火铳台/投石机
                                  ↑
                            递运铺延长射程
                            烽火台供电覆盖（攻坚塔必需）
```

- 每座军械坊有射程，塔在射程内才收到弹药；超距则需在中间建递运铺接力。
- 弹药按每塔消耗速率持续扣减；产需不平衡时，玩家需扩军械坊或节流（少建高耗塔）。
- **战术深度**：倭寇头目可优先击毁补给节点，玩家需保护粮道——"守"从守城墙扩展为守整条供应链。

### 4.4 资源系统

| 资源 | 用途 | 来源 |
|---|---|---|
| 银两 | 造塔、造建筑、升级 | 市集、击杀奖励 |
| 粮草 | 出兵 + 军械坊原料 | 粮仓、波次结算 |
| **箭支/火药/石弹** | 炮塔弹药（消耗品） | 军械坊生产，经补给线送达 |
| 香火 | 英雄技能 | 汤和祠、击杀、文化事件 |
| 文化点 | 星级评定、图鉴解锁 | 击杀倭寇、文化事件、建筑 |

### 4.5 英雄与技能（汤和）

- 英雄"汤和"立绘/棋子在城堡处，技能消耗香火，有冷却：

| 技能 | 效果 | 文化来源 |
|---|---|---|
| 巡游 | 全军移速+攻速提升 8s | 汤和信俗巡游 |
| 拼字龙灯 | 指定路范围眩晕+伤害 | 拼字龙灯 |
| 抗倭令 | 全塔射速提升 + 城堡修复 | 抗倭叙事 |
| 望海 | 短时揭示全图并给据点造成一次伤害 | "望"之终极技 |

### 4.6 文化闯关系统（差异化核心）

- **文化事件卡**：每关达成条件触发（如"集齐 3 座书院""守住城门 60 秒"），弹出一张图文卡，讲述永昌堡/汤和的一段史实，并给予增益。
- **图鉴**：敌人、兵种、建筑、事件均有条目；部分图片**直接使用官方素材包中的图片**（见第 9 节授权提醒）。
- **星级条件**（每关 3 星）：① 守住城堡；② 摧毁据点；③ 达成文化目标（如文化点达标 / 未损失任一建筑）。

## 6. 数值框架（初始基线，可调）

- 城堡 HP 1000；据点 HP 800；出兵冷却 1.2s（兵营每级 -0.15s）。
- 经济：市集 3 银/秒，粮仓 4 粮/秒（初始各 1 座）。
- **弹药链（v0.2）**：军械坊 1 座产箭支 2/s、火药 1/s 或石弹 0.5/s（切换配方）；箭塔每发耗 1 箭支、火铳台 2 火药、投石机 2 石弹；弹容箭塔 20 / 火铳台 16 / 投石机 12。补给射程军械坊 180，递运铺 +160 接力。
- **供电网（v0.2）**：烽火台覆盖半径 220；火铳台/投石机无覆盖时射速 -50% 且不可达满级输出。
- 合成：2×1★→1×2★（属性 ×2.2）；2×2★→1×3★（属性 ×2.4）——与 Mindustry Reconstructor 同构，方向已验证。
- 波次强度：`enemy_hp = base * (1 + 0.18 * wave) * chapter_mult`。
- 相克伤害系数：克制 ×1.5，被克 ×0.7，其余 ×1.0。
- 详细数值见 `data/*.csv`，建议使用 Godot `Resource`/CSV 数据驱动，改表不改代码。

## 9. Godot 实现方案

**工程结构**
```
res://
├─ autoload/        GameState.gd  EventBus.gd  ResourceManager.gd  DataDB.gd  AudioManager.gd
├─ scenes/
│  ├─ Main.tscn                 主场景
│  ├─ battlefield/  Battlefield.tscn  Lane.tscn  BuildSlot.tscn
│  ├─ units/        Unit.tscn   6 种单位皮肤
│  ├─ towers/       Tower.tscn  4 种塔
│  ├─ buildings/    Building.tscn
│  ├─ enemies/      Enemy.tscn
│  └─ ui/           HUD.tscn  UnitCard.tscn  CultureCard.tscn  Codex.tscn
├─ data/            *.csv（见 design/data/）→ 导入为 Resource
├─ art/  audio/     （资产 + LICENSE）
└─ scripts/         纯逻辑类（无场景依赖）
```

**关键技术点**
- **性能优化（暴兵核心）**：单位与抛射物使用**对象池**（`ObjectPool`），避免频繁 `queue_free`/`instantiate`；同屏单位上限定 200。
- **移动**：沿路用 `Path2D` + `PathFollow2D` 或路点插值前进；遇敌停下攻击。不必用完整 Navigation2D。
- **合成**：在待命区与场上单位中按 `unit_type+star` 分组，达到 2 个即合并、升星、替换节点。
- **数据驱动**：`DataDB` 在 `_ready()` 解析 CSV 成 Dictionary（`unit_id → stats`），所有数值从表读。
- **信号解耦**：`EventBus` 发布 `unit_merged` / `wave_cleared` / `culture_unlocked` / `tower_out_of_ammo` / `supply_cut` 等，UI 与逻辑分离。
- **补给链（v0.2）**：`SupplySystem` autoload 每帧维护"军械坊→塔"的可达图（按距离+递运铺接力），按塔 `ammo_per_shot` 扣减弹容；烽火网用 `PowerNet` 计算覆盖。断供/断网通过 EventBus 驱动 UI 警示。
- **存档**：`user://save.json` 记录章节星级与图鉴。
- **目标平台**：优先 Windows 10/11（赛事硬性要求）；导出预设一并提交。

## 12. 风险与取舍

- **素材授权风险（重要）**：`../docs/01-参考资料包/` 中的"汤和信俗素材包"与"永昌堡参考资料 PDF"**未声明开放许可**。用于参赛必须在《素材声明》中逐项列明来源/作者/许可；如许可不明，**仅作内部参考、不直接进入成品**，改用自绘/CC0 资产。
- **复杂度风险**：四系统（暴兵/塔防/补给/文化）叠加易失控。**先做单路闭环再扩张**；补给链分三层：第一层（断供停火）必做，第二层（烽火供电）建议，第三层（水渠冷却）有余力再做。若时间不足，"建筑"简化为粮仓/军械坊/烽火台 3 种。
- **性能风险**：暴兵同屏单位多，务必先做对象池与同屏上限；补给链可达图按建筑变动重算，勿每帧全量遍历。
- **文化表达风险**：避免"单纯堆砌图片文字"（评审明确不计突出表现），要把文化元素**嵌入玩法机制**（藤牌克弓、龙灯增益、进士光环等）。
