# 《守望 · 永昌》游戏设计大纲

> 类型：Vampire Survivors-like / 割草生存 Roguelite
> 版本：v0.1（2026-11-23，旧守城代码清空后重写）
> 引擎：Godot 4.7.2-stable，2D，GDScript
> 单局时长：16 分钟；目标平台：Windows / Linux 桌面，1280×720 起

---

## 1. 一句话概念

**你是永昌堡外最后一盏灯。**

倭寇围城的夜里，你孤身守在城外滩涂与街巷之间，自动挥刀、放箭、开铳，
在潮水般的敌人中撑到黎明；每一次升级都在“兵器、阵法、灯火”之间做取舍。

---

## 2. 主题落点：守 · 望

- **守**：不是造塔守城，而是**人守在人海里**。玩家是城墙外的第一道防线。
- **望**：望楼灯是核心资源。灯火越亮，视野与拾取范围越大，但会吸引更多敌人；
  灯油耗尽则进入“摸黑”高风险高收益状态。
- **文化**：永昌堡、十三进士、王沛/王德乡兵、拼字龙灯、汤和信俗、拦街福。
  文化不是贴图，而是玩法：阵法、灯火、龙灯拼字、百家宴士气。

---

## 3. 核心循环

### 3.1 30 秒循环

移动躲包围 → 自动攻击 → 拾取军功/灯油 → 升级三选一 → 继续推进。

### 3.2 16 分钟单局

| 时间 | 事件 | 目的 |
|---|---|---|
| 0:00 | 夜袭开始，初始兵器 | 教学：移动、拾取、升级 |
| 2:00 | 第一波倭寇斥候 | 建立压力 |
| 4:00 | 藤牌武士小队 | 检验破甲需求 |
| 6:00 | 火枪倭出现 | 远程威胁，要求走位 |
| 8:00 | 精英“倭将” | 第一个构筑检查点 |
| 10:00 | 灯油事件：油尽/添油二选一 | 风险收益抉择 |
| 12:00 | 混编潮 + 旗手 | 士气与清屏能力检验 |
| 14:00 | 第二倭将 + 大名先锋 | 终局前压力 |
| 15:30 | 大名入场 | Boss 战 |
| 16:00 | 黎明钟响 | 结算、解锁 |

### 3.3 跨局循环

军功 → 解锁角色/兵器 → 银两 → 永久小加成 → 更高难度 → 图鉴与剧情碎片。

## 4. 操作

| 输入 | 行为 |
|---|---|
| WASD / 方向键 | 八向移动 |
| 鼠标 / 右摇杆 | 手动瞄准（默认自动索敌） |
| 自动 | 兵器按冷却自动释放 |
| 空格 | 冲刺（短无敌，冷却 3s） |
| 1 / 2 / 3 | 升级三选一 |
| Esc | 暂停 |
| Tab | 查看构筑与图鉴 |

**原则**：单手可玩；不需要点击攻击；所有攻击自动索敌，玩家只负责走位与选择。

## 5. 局内成长

### 5.1 等级与经验

- 单局 1–30 级；经验来源：军功袋（小/中/大）、精英掉落、灯油罐。
- 经验曲线：`need(n) = 5 + 4n + 0.35n²`，30 级约 16 分钟。
- 升级立即暂停，给出 3 张卡：新兵器 / 兵器升级 / 被动 / 补给。
- 满级兵器不再出现在卡池；卡池按权重抽取，避免死卡。

### 5.2 构筑槽位

- 6 个兵器槽 + 6 个被动槽。
- 兵器最高 8 级；被动最高 5 级。
- 进化：**兵器满级 + 指定被动满级 + 精英掉落“图纸”** → 局内进化。

### 5.3 灯火（本作差异化）

- 初始灯火半径 220px；每 30s 消耗 1 格灯油，共 6 格。
- 灯火越亮：拾取半径 +、暴击 +、敌人索敌范围 +（更危险）。
- 灯油为 0：视野缩到 120px，敌人 +30%，经验 +50%，可主动“摸黑”刷级。
- 拾取灯油罐回复 2 格；精英必掉 1 罐。

铁枝（击退）、五色纸（元素）、望海（冷却）。

### 8.1 波次生成

- 基础密度：`spawn/s = 2 + 0.35 * minute`，上限 900 存活。
- 每 60s 一次“潮”：环形包围 + 一个方向缺口。
- 精英每 6 分钟一个；Boss 固定 15:30。
- 屏幕外 1.2 屏生成，避免贴脸刷怪。

## 10. 文化系统

- **拼字龙灯**：集齐红/黄/蓝/绿/黑 5 枚龙鳞，触发“天下太平”全屏控制 8 秒。
- **十三进士**：每局随机 1 位进士残影提供祝福（暴击/经验/护甲/冷却）。
- **百家宴**：地图上的供桌，交互后全队回复并短暂加速。
- **汤和信俗**：Boss 前出现香火点，选择“祭先烈”（攻）或“祈平安”（守）。
- **寓兵于民**：局外升级树，用银两提升民兵、屯田、匠作三条线。

文化内容全部可跳过，不影响通关；收集后进入图鉴。

---

## 11. 局外成长

- **军功**：解锁角色、兵器、地图；不可购买数值。
- **银两**：永久小加成（每项 +3%~8%，有上限），避免滚雪球。
- **图鉴**：敌人、兵器、进士、民俗条目；完成度给外观。
- **难度**：夜一至夜五；敌人血量/密度/精英词缀递增。
- **存档**：`user://save.json`，版本号 + 迁移函数。

---

## 12. 数值基线

- 玩家基础：HP 100，移速 150px/s，拾取 48px，冲刺 0.18s。
- 敌人基础：HP 10（斥候）~ 800（倭将）~ 12000（大名）。
- 伤害预期：0 分钟 DPS 25；8 分钟 180；16 分钟 900。
- 目标：普通玩家 3–5 局通关夜一；熟练玩家 1 局。
- 失败条件：HP 归零；复活道具每局 1 次。

---

## 13. 美术与音频

- **像素规格**：角色 64×64，敌人 32–96，图块 32×32，投影 2:1。
- **调色**：青灰城墙、暖红/金、米色土路、墨绿芦苇；限制 32 色主盘。
- **工具**：`skills/pixel-art-studio/`（Pillow 程序化像素流水线）。
  新素材统一放 `pixel-art/<slug>/build.py`，导出到 `game/assets/`。
- **现有资产**：`game/assets/units/` 11 组兵种可复用为角色/敌人原型；
  `game/assets/tiles/dcss/` 图块可复用为地面；音频与字体保留。
- **音频**：保留 CC0 音效与 CC-BY BGM；新增音效登记到 `素材授权清单.csv`。
- **UI**：血条、经验条、灯火格、兵器槽、计时器、击杀数；像素字体用霞鹜文楷。

## 14. 技术方案

### 14.1 工程结构

```
game/
  project.godot
  scenes/        main_menu.tscn / run.tscn / credits.tscn
  scripts/
    autoload/    GameState / SaveSystem / AudioBus
    core/        run_director / spawner / xp / loot
    combat/      weapon_base / projectile / damage
    actors/      player / enemy / elite / boss
    ui/          hud / level_up / pause / codex
  data/          weapons.json / enemies.json / waves.json / characters.json
  assets/        units / tiles / ui / audio / fonts
  tests/         smoke / balance
```

### 14.2 性能

- 目标：1280×720、400 敌人、60fps；低配 30fps 可玩。
- 小怪用 **数据数组 + MultiMeshInstance2D** 渲染，逻辑走空间哈希（64px 格）。
- 精英/Boss 用独立 `CharacterBody2D`；弹幕与经验袋对象池。
- 伤害数字与粒子限流；同屏粒子上限 300。
- 所有生成用固定种子，便于复现与平衡测试。

### 14.3 数据驱动

- 兵器、敌人、波次、角色全部 JSON；改数值不改代码。
- 兵器行为用 `WeaponPattern` 枚举 + 参数（扇形角、弹速、穿透、冷却）。
- 波次表按秒配置：`{t, enemy, count, pattern, elite}`。

### 14.4 测试

- `gda script run res://tests/smoke.gd --project game`：启动、生成、升级、结算。
- 无头跑 16 分钟加速模拟：检查卡死、NaN、对象泄漏。
- 截图验收：主菜单、战斗、升级、Boss、结算、滚幕。
