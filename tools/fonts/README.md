# Font build source

`LXGWWenKai-Regular-full.woff2` is the unmodified LXGW WenKai Regular
distribution used only as the build input. It is not part of the Godot project
or an exported game.

The runtime font is generated by:

```bash
bun run assets:font
```

That command extracts only glyphs reachable from runtime strings and writes
`game/assets/fonts/LXGWWenKai-Regular.woff2`. The generated font keeps the
original `name` table and is distributed under SIL Open Font License 1.1. The
OFL additional permission covers this subsetted WOFF2 used for in-game delivery;
do not redistribute it as an installable desktop font. See
`game/assets/fonts/OFL.txt`.

Run `bun run assets:font -- --check` in CI to verify that the committed subset
is current.
